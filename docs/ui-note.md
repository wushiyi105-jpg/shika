# UI 说明：识卡

- **谁在什么时刻打开**：给展会后要整理联系人的人。
- **首屏任务句**：这叠名片，半小时清完。
- **主操作**：按「批量拍名片 → 逐张确认字段 → 导出 vCard / CSV」推进；首屏先给输入和主按钮，结果区在下方或右侧。
- **主信息结构**：名片桌垫；对比、时间线、原文与修订、队列或价签按任务选择，而不是通用卡片堆叠。
- **三种状态**：空状态指到第一步；已有内容显示结果、来源/计算依据和导出入口；失败或待确认时保留已填内容，并在原位置说明缺什么。
- **视觉原型**：名片桌垫。底色、强调色、圆角、边框和数字字体都按该任务重定，遮住产品名后仍能从布局看出用途。
- **解释**：给展会后要整理联系人的人：批量拍名片，逐张确认姓名、公司、电话、邮箱并定位原图；疑似重复可合并，也可分别存。
